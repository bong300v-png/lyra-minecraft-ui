FAQ

What if I use another Launcher?

+

At this time we only actively update CurseForge, so we recommend using these for automatic updates and fixes for when Pixelmon Mod updates and custom content additions. Other launchers can be updated manually if needed however!

How can I install shaders as well?

+

You can manually add shaders by downloading the NeoForge version of "Iris" for 1.21.1 and adding it to your Mods folder within CurseForge. You can get it at this link: https://www.curseforge.com/minecraft/mc-mods/irisshaders. You will now see an Iris option in video settings where you can drag and drop in shader packs!

Can I play with friends?

+

You can play with friends at any time on Pixelmon! When in-game use the /friends and /tpa commands to go to eachother!

Why do all my items look like paper or basic minecraft textures?

+

This may mean you do not have the resourcepack installed, you can use /resourcepack in-game to download our textures and custom items!

Is the server cracked?

+

The server is not cracked and it is required to have a valid Minecraft Java account to play
